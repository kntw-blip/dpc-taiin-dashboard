# DPC退院患者調査ダッシュボード（令和6年度）

厚生労働省「DPC導入の影響評価に係る調査『退院患者調査』」（令和6年度）の公表データを可視化し、選択した病院（自院）を同じ二次医療圏の病院・同じ法人の病院と比較するサイトです。

※ 作成中

## 仕組み
- `.github/workflows/fetch-raw.yml`：`scripts/fetch.py` で一次データを取得し、`raw` ブランチに保存

- 厚生労働省「医療情報ネットのオープンデータ」
- 国土交通省「国土数値情報（医療圏データ）」
