# DPC退院患者調査ダッシュボード（令和6年度）

厚生労働省「DPC導入の影響評価に係る調査『退院患者調査』」（令和6年度）の公表データを可視化し、選択した病院（自院）を **同じ二次医療圏の病院**、**同じ法人の病院**、または **病床数・病床機能が近い類似病院** と比較するサイトです。病院の外部環境（地域での立ち位置・競合状況）を把握し、投資判断の材料にすることを目的としています。

**公開サイト**：https://kntw-blip.github.io/dpc-taiin-dashboard/

## できること
- 自院を病院名で検索して選択（全国6,370施設：DPC参加・準備・出来高算定病院）
- 比較軸の切り替え：二次医療圏（第8次医療計画の330圏）／法人（開設者）／類似病院
  - 類似病院：入院基本料の系統（特定機能病院・急性期一般1・急性期一般2〜3・急性期一般4〜6・地域一般・専門病院・届出なし）が同じ病院を候補とし、「|log(総病床数の比)| ＋ 病床構成5区分（DPC算定・回復期リハ・地域包括・療養・精神）の割合の差の合計」が小さい順にN施設（初期値30、スライダーまたは数値入力で変更）。地域は全国／同じ地方／同じ都道府県
- 比較対象の範囲：DPC参加・準備病院のみ／出来高算定病院も含む
- 指標（令和5年度との前年比つき）
  1. 規模：退院患者数、病床数・病床構成、病床あたり退院患者数
  2. 疾患構成：MDC別シェアと順位、MDC構成比、病院×MDCヒートマップ、医療圏の患者の流出入
  3. 効率性・複雑性：在院日数の指標、患者構成の指標（全体・MDC別）、平均在院日数
  4. 救急：救急搬送入院、救急医療入院。入院区分（予定入院・化学療法の再入院・予定外入院・救急医療入院）のMDC別分析（秘匿1区分は差し引きで推計）、救急搬送入院のMDC別分析（救急搬送入院率・シェア・疾患構成）
  5. 地域連携：紹介率、入院経路、退院先
  6. 手術・高度医療：手術・化学療法・放射線療法・全身麻酔
  7. 医療の質：死亡退院率、4週以内の計画外再入院率
  8. 薬剤：後発医薬品の使用割合
  10. 重症度・リハビリ：回復期リハのFIM（入棟時・退棟時の点数帯、運動FIM 53点以上の割合の増加）、疾患別の重症度16項目（脳卒中のmRS・発症時期、Killip分類、肺炎の重症度など）。おおよその対象患者数を併記
  9. 手術別の実績：DPC6桁の疾患×手術区分（667区分）ごとの件数・平均在院日数。自院の主要な手術、手術を選んでの比較（疾患名・手術名・Kコードで検索）、手術シェアのヒートマップ
  12. 疾患別の推移（令和元年度〜令和6年度）：疾患（DPC上6桁）を選び、自院の手術あり／なしの件数、手術ありの割合（自院・比較対象全体）、比較対象全体の件数と自院のシェア、手術あり／なし別の平均在院日数。10件未満の非公表セルは全国の施設類型別合計との差から推計（幅も表示）
  11. 経年推移（令和元年度〜令和6年度）：主要8指標の推移（自院・他院の中央値・中央50%の範囲）、指標を選んで各病院の推移・自院の順位・起点の年度からの変化、MDC別の患者数とシェアの推移、自院のMDC別の増減。サマリーにも自院の推移を表示
  12. 疾患別の推移（令和元年度〜令和6年度）：疾患（DPC上6桁）を選び、自院の手術あり／なしの件数、手術ありの割合（自院・比較対象全体）、比較対象全体の件数と自院のシェア、手術あり／なし別の平均在院日数。10件未満の非公表セルは全国の施設類型別合計との差から推計（幅も表示）
- 使い方の説明：画面右上の「使い方」パネル（はじめに・画面の見方・各セクション・用語集・よくある質問）、初回に自動で始まるガイドツアー（パネルから再生可）、各チャートの「？」（何を表すか・読み方・読み方の例・注意点）、自院を選ぶ前の画面の3ステップ案内と例の病院。説明文は `site/help.js` にまとめています
- スマホ（幅720px以下）では、下にスクロールすると上部の条件欄が1行の要約に縮む（「条件を変更」で開く、「条件を閉じる」で戻す）
- すべてのチャートに表表示、比較表のCSVダウンロード、URLで条件を共有（`?h=告示番号&d=疾患コード&axis=area|corp|peer&scope=dpc|all&region=all|reg|pref&n=30`）

## 仕組み
1. `.github/workflows/fetch-raw.yml`：`scripts/fetch.py` が厚労省・地方厚生局・国土数値情報から一次データを取得し、`raw` ブランチに保存
   - `.github/workflows/fetch-dis.yml`：`scripts/fetch_dis.py` が令和元年度〜令和6年度の疾患別手術別集計・疾患別手術有無別処置1有無別集計（MDC別）と施設類型別の合計を取得し、縦長のCSVにして `raw-dis` ブランチに保存
   - `.github/workflows/fetch-hist.yml`：`scripts/fetch_hist.py` が令和元年度〜令和5年度の退院患者調査の集計表（推移に使う表だけ）を取得し、`raw-hist` ブランチに保存
   - `.github/workflows/fetch-dis.yml`：`scripts/fetch_dis.py` が令和元年度〜令和6年度の疾患別手術別集計・疾患別手術有無別処置1有無別集計（MDC別）と施設類型別の合計を取得し、縦長のCSVにして `raw-dis` ブランチに保存
2. `.github/workflows/build.yml`：
   - `scripts/kousei_parse.py`：地方厚生局「コード内容別医療機関一覧表」から病院と開設者を抽出
   - `scripts/match_owner.py`：退院患者調査の施設と照合（名称・所在市区町村・病床数）し、法人を付与
   - `scripts/build_data.py`：集計表をJSONに加工（年度の途中で合併した病院の2行は `scripts/dupmerge.py` で1行にまとめる：件数は合計、平均・率は件数で、1か月あたりの件数は提出月数で重み付け）
   - `scripts/build_sev.py`：FIM・重症度等の入力状況からリハビリ・重症度データを作成
   - `scripts/build_surg.py`：疾患別手術別集計（MDC別）と DPC電子点数表（手術名・Kコード）から手術別データを作成
   - `scripts/build_hist.py`：各年度の施設概要表の「通番」（前年度の告示番号）をたどって令和6年度の病院に過去5年分をつなぎ、経年推移データを作成（年度途中の合併は合算、閉院等の病院は医療圏別の合計）
   - `scripts/build_dis.py`：疾患別の手術あり／なし（輸血のみは「なし」）の推計値・幅・平均在院日数を病院×年度で作成（site/data/dis/）
   - `scripts/build_dis.py`：疾患別の手術あり／なし（輸血のみは「なし」）の推計値・幅・平均在院日数を病院×年度で作成（site/data/dis/）
   - `site/` を `gh-pages` ブランチに公開
3. `site/`：静的サイト（ECharts）

## 法人（開設者）の手修正
照合できなかった施設は「法人不明」になります。一覧は公開サイトの `data/owner_review.csv` にあります。
`data/owner_override.csv` に行を追加して main にプッシュすると、次のビルドから反映されます。

```csv
kokuji,corp_name,note
30530,小田原市|神奈川,小田原市立総合医療センターに名称変更
```
- `kokuji`：退院患者調査の告示番号（5桁）
- `corp_name`：法人のキー。同じ法人の病院と同じ値にしてください（比較表の「法人」列で確認できます）。空欄にすると「法人不明」扱いになります。

## 注意事項
- 集計対象は令和6年6月〜令和7年5月の退院患者。10件未満は秘匿（–）。
- 経年推移の令和元〜5年度は各年度の報告書の値（4月〜翌3月）。令和6年度だけ集計期間が6月〜翌5月のため、令和5年度との間に区切りを入れています。在院日数の指標・患者構成の指標は各年度の全国平均に対する値です。比較対象は令和6年度の顔ぶれで固定しています。
- 法人は令和8年10月時点の開設者で、診療実績の時点とは異なります。法人格の単位で、同名の別法人は代表者名で区別しています。
- 二次医療圏は国土数値情報（2020年版）に秋田県の再編（8圏→3圏）を反映して割り当てています。
